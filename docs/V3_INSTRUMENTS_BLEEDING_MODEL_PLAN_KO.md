## 0. 결정 사항 (소유자 결정, 2026-10-24)
1. **안전 범위: "실제 수술처럼 구현".** 상황에 맞는 기구를 고르고 해당 부위에 사용하는 흐름까지 구현한다. 처리하지 않고 계속하면 실제처럼 악화되거나 실패한다.
   - 장비 출력·흡인 압력 같은 수치와 약물 용량은 넣지 않는다. 게임 진행에 필요하지 않고, 검증되지 않은 수치가 실제 지침처럼 오해될 수 있기 때문이다. SAFETY.md에 이 개정을 기록한다.
2. **기준 브랜치:** `claude/kind-ride-y03hcc`를 기준으로 하고, `improve/surgeon-gameplay`의 고유 기능을 옮겨온다.
   - 옮겨올 기능: 점탄물질·수력분리 단계, 전낭 방사상 파열, 시간이 지나면 줄어드는 조직 스트레스와 경고, 실제 시간 기준의 핵 제거 속도, 3D 합병증 표시.
3. **모델링:** 코드로 생성하는 절차적 모델링에 에셋 로더를 더한다. 라이선스 정보가 있는 OBJ 파일만 불러온다.

- 기구 선택: **T**(다음), **Shift+T**(이전), 트레이 클릭.
- 기구 사용:
  - 단계 기구(각막도, 낭절개침, 초음파 등)는 기존처럼 클릭·드래그로 단계 과제를 수행한다.
  - 나머지 기구는 해당 부위를 클릭하면 사용된다(`use`).
- 자동 기구(튜토리얼·표준)는 **단계 기구만** 자동으로 쥐어 준다. 상황 기구는 항상 집도의가 직접 고른다.
- 튜토리얼에서만 힌트에 기구 이름을 보여 준다. 표준은 징후만, 고난도는 힌트 없이 진행한다.

## 2. 합병증 처리 흐름
1. 합병증이 생기면 안전 정지와 방치 타이머가 시작된다(기존과 같음).
2. **A(평가)** 를 누르면 징후를 확인하고 타이머가 멈춘다.
3. 처치가 필요한 합병증은 '처치 대기' 상태가 된다. 맞는 기구로 해당 부위에 사용하면 해결된다(관리됨).
4. 처치하지 않고 계속하면 결과가 달라진다.
   - **중등도 합병증:** 계속할 수 있지만 악화된다.
   - **중대 합병증(후낭 파열, 맥락막위 출혈):** 단계 작업을 계속하면 **중대 실패**다.
5. 후낭 파열은 **B(상급자 호출)** 로 관리한다. 이후 IOL은 섬모체고랑에 고정된다.
6. **X(안전 중단)** 는 언제나 가능하다.

| 합병증 | 단계 | 처치 | 처치하지 않으면 |
|---|---|---|---|
| 환자 움직임, 모니터 경보 | 전낭절개, 유화술 | A 평가 | — |
| 각막 혼탁 | 피질 제거 | A 평가 | — |
| 절개부 출혈 (신규) | 절개 | 소작기 → 절개부 | 혈액 막으로 시야 흐림 지속 |
| 동공 축소 | 유화술 | 홍채 갈고리 → 동공 가장자리 | 작업 범위 축소 |
| 홍채 탈출 (이식) | 유화술 | 홍채 갈고리 → 동공 가장자리 | 계속 제거하면 홍채 손상 → 전방 출혈 |
| 소대 약화 (이식) | 전낭절개 | 수정체낭 긴장링 → 낭 안 | 스트레스 2배, IOL 편위 |
| 전낭 방사상 파열 (이식) | 전낭절개 | 점탄물질 캐뉼라 → 전방 | 유화술 중 후낭 파열 |
| 전방 출혈 (신규) | 유화술 | 세척 캐뉼라 → 중앙 | 시야 저하, 스트레스 증가 |
| 후낭 파열 (중대) | 유화술·피질 | B 상급자 호출 | 계속 제거하면 **중대 실패**(핵 낙하) |
| 맥락막위 출혈 (신규, 중대) | 피질 제거 | 봉합사 → 주절개 즉시 봉합, 이후 안전 중단 | 단계 작업을 계속하면 **중대 실패** |
| IOL 편위 | 마무리 | IOL 조작 갈고리 → 중심 | 정렬 확인 불가 |
| 절개창 누출 | 마무리 | 봉합사 → 주절개 | 종료 보류 |

**결과**
- 완료, 합병증 관리 완료, 안전 중단, 중대 실패의 기존 4종에 **"합병증 미해결 완료"** 를 추가한다.
- 기구를 잘못 쓰면 안전 점수에서 2점씩 깎는다.
- 미해결 합병증이 남은 채 끝나면 안전 점수는 0점이다.

## 3. 수술 단계 보강 (이식)
- 점탄물질: 주절개 후 전방에 채우고, IOL 전에 낭 안에 채운다. 채우지 않으면 전낭절개 허용 범위가 좁아지고 파열이 빨리 일어난다.
- 수력분리: 핵 제거 전에 한다. 생략하면 핵 제거 중 스트레스가 쌓인다.
- 핵 제거와 피질 제거는 실제 시간 기준으로 각각 약 4초, 3초 걸린다.
- 조직 스트레스는 시간이 지나면 줄어들고, 50%에서 경고한다.

## 4. 환자 모델
- 증례마다 합성 환자 프로필을 둔다: 나이, 동반질환(고혈압, 당뇨, 고도근시), 복용 약물 종류(항응고제, 알파차단제 — 약 이름과 용량은 없음), 불안도.
- 활력징후는 기준값에서 시작해 사건(통증, 출혈, 움직임)에 따라 목표값으로 서서히 움직인다. 예: 맥락막위 출혈 시 혈압과 심박이 오른다.
- 위험 요인은 출혈 정도에 반영된다(항응고제 → 출혈이 더 진함).
- 수술 전 화면에 환자 차트를 표시한다(합성 데이터 표시 포함).

## 5. 안구 모델링 (절차적)
- **2D:**
  - 홍채: 결 무늬, 와, 칼라렛
  - 윤부, 결막 혈관
  - 개검기와 눈꺼풀, 드레이프
  - 적색반사(핵 제거 후 동공 안이 붉게 빛남)
  - 출혈: 절개부 혈액 막, 전방 아래 혈액층, 적색반사 소실
  - 손에 든 기구의 끝 모양 표시
- **3D:**
  - 홍채 결과 공막 혈관을 셰이더 노이즈로 표현, 적색반사, 개검기·드레이프 메시
  - 합병증 표시(이식 + 출혈 메시 추가)
- **에셋 로더** `assets.py`:
  - `assets/models/<이름>/model.obj`와 `manifest.json`(이름, 출처, 작성자, 라이선스)이 모두 있을 때만 해당 메시를 실물 모델로 교체한다. 교체 대상은 sclera·iris·lens·cornea이다(IOL은 셰이더 접힘 때문에 제외).
  - 라이선스 정보가 없으면 불러오지 않는다(SAFETY.md의 에셋 출처 규칙).
