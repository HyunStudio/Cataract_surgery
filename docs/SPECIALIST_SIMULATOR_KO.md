# OphthoSim 전문 수술 시뮬레이션 게임 — 2026-10-28

기본 실행 모드는 Godot 기반 통합 시뮬레이션입니다. 준비부터 현미경 조작, 조직 반응, IOL 전달, 최종 검사와 복기까지 하나의 상태로 이어집니다. 실제 수술처럼 기구와 장비를 조작하는 게임을 목표로 합니다. 현재 시각 표현은 절차적으로 생성한 3D 모델이며, 조직·유체·광학은 비보정 근사 모델입니다.

## 실행

Windows 배포 ZIP을 풀고 `OphthoSim-Surgical.exe`를 실행하세요. 같은 폴더의 `.pck`가 필요하며 Python/Godot 설치는 필요 없습니다. 소스 실행은 저장소에서 `powershell -ExecutionPolicy Bypass -File tools/run-godot.ps1`입니다. `-Editor`는 편집기, `-Game`은 이전 절차형 게임을 엽니다.

## 시작과 진행

표준·고밀도 수정체·작은 동공·환자 움직임 중 사례를 고르고 환자·부위·장비 세 항목을 확인한 뒤 집도를 시작합니다. 자유 연습은 진입부가 준비된 별도 모드이며 정상 증례 완료로 판정하지 않습니다.

정규 사례는 절개도의 연속 경로로 진입부를 형성합니다. 기구는 절개부를 중심으로 방향과 삽입 깊이가 결정됩니다. 전낭의 절개·파지·견인에 따라 실제 메시 연결이 끊어지고, 유화는 국소 연결을 분해하며 흡인은 분리된 재료를 팁으로 이동시켜 제거합니다. 한 위치에 페달을 누른 채 기다리는 것으로 수정체 전체가 사라지지 않습니다. 핵과 피질은 서로 다른 연결 파괴 기준을 사용하고, 캐뉼라는 받아들여진 유입량에 따라 가까운 피질 부착을 풀며, 관류·흡인은 풀린 피질 연결을 국소적으로 박리합니다. 화면의 핵·피질 %는 초기 수정체 총질량을 기준으로 합니다.

잔여물 제거 후 인젝터의 입력을 유지하면 IOL이 전달되고, 놓으면 전달이 멈춥니다. 탄성 복원으로 전개되며 위치 조정 기구의 접촉으로 중심이 변합니다. 부분 전달 중인 인젝터는 원래 손에 유지됩니다. 기구를 인출하고 진입부가 안정되면 잔여물·IOL·진입부 세 검사를 수행하고 종료하세요. 이 판정은 시뮬레이션 상태 확인이며 임상 술기 등급이 아닙니다.

## 입체 안구와 깊이 조작

기본 모드는 1mm당 0.24 모델 단위의 대표 안구 형상을 사용합니다. 수정체 직경 9.2mm·두께 4.2mm, 중앙 전방 깊이 3.0mm, 중앙 각막 두께 0.55mm를 기준으로 낭·홍채·각막 안팎 표면과 수치 입자를 함께 생성합니다. 이 값은 특정 환자나 장비의 보정 데이터가 아닙니다. 수정체 수치는 [Xue 등의 측정 연구](https://onlinelibrary.wiley.com/doi/10.1155/2019/8319027)를 참고한 대표값이며, 곡면과 물성은 여전히 공학적 근사입니다.

각막에 두께가 생겼으므로 절개 통로를 지난 뒤 전방 안에서 방향을 바꿔야 합니다. 마우스 조준은 목표 깊이 평면을 따르며, Q/E와 휠로 각도·삽입 깊이를 조절합니다. 절개 진입 깊이와 낭의 깊이는 다릅니다. 인출 버튼은 현재 축 방향의 인출을 요청하며, 통로와 정렬되지 않으면 접촉에 의해 멈출 수 있습니다. 먼저 열린 통로로 기구를 이동하세요. 이는 시뮬레이터 조작 설명입니다.

표시 모델의 손잡이는 수술 시야 밖에 두고, 작업부와 가는 축을 구분했습니다. 도구별 팁 반경은 접촉 판정에도 쓰지만 축·날·열린 집게 턱 전체의 충돌은 다음 구현 범위입니다. 결과의 길이·면적은 대표 형상의 mm/mm²이며 유량·에너지·손상 노출 값은 상대 모델 값입니다.

수류는 실제 받아들여진 유입량만으로 피질 표면의 연결 노출장을 구동합니다. 이 장은 이웃 사이에서 퍼지고 완화되며 부착을 줄이는 근사로, 별도의 유체 체적을 추가하지 않습니다. 유리체·낙하 핵·IOL 지지 상실과 합병증 회복은 아직 구현되지 않았습니다. 원형 절개 후 낭편의 파지·분리·반출, 기구 교체 시 완전한 인출/재진입 절차와 전체 포인터 조작 검증도 남아 있습니다.

## 조작

분리된 전낭편은 집게로 잡고 실제 열린 통로를 통과시켜 꺼냅니다. 조각이 안구 안에 남거나 파지를 해제하면 자동으로 사라지지 않습니다. 기본 증례 완료에는 인출 증거와 잔류 분리편 확인이 필요합니다. ‘기구 인출’ 버튼은 현재 축을 따라 충돌 검사를 거치는 이동을 요청하므로 먼저 열린 절개창에 기구를 맞춰야 합니다.

장비 콘솔에서 유입·흡인·유화 상대값과 초점·조명을 조절합니다. 균형·저자극·고밀도 프리셋이 있습니다. 모든 장비 값은 게임 상대값이며 실제 장비 단위가 아닙니다. 도움말에서 마우스 깊이 보조, 높은 대비, 모니터 움직임 감소, 장비 소리를 바꿀 수 있습니다.

포커스 이탈·카메라 전환·도움말·일시정지·복기는 동작을 해제합니다. 페달을 놓고 새로 눌러야 재개됩니다. 움직임·구조 손상 경보는 평가하기 전까지 진행을 멈춥니다. 구조 손상은 확인 후에도 남으며 해당 증례를 정상 완료할 수 없습니다.

## 기록과 복기

결과에는 전낭편 인출 개수·면적·잔류 분리편 면적, 경과 시간·기구 경로·에너지 노출·접촉 시간·조직 연결 파손·잔여량·IOL 정렬·누출과 사건 이력이 표시됩니다. 복기 슬라이더는 약 2초 간격으로 기록된 3D 상태를 최대 900장 보여줍니다. 실시간 모델을 되감거나 재계산하는 결정론적 입력 리플레이는 아닙니다. 저장 경로는 화면에 표시되며 일반적으로 `%APPDATA%/Godot/app_userdata/OphthoSim Surgical Simulator/` 아래입니다. 파일당 32MB 한도가 있습니다.

## 현재 구현의 경계

전낭은 217개 정점의 XPBD 막으로, 절단으로 지지 면이 없는 연결을 제거하고 실제 연결 성분을 추적합니다. 분리편은 양쪽이 같은 구획 유체에 노출되므로 낭 경계의 구획 차압을 받지 않습니다. 접촉은 막 정점의 각막/홍채 높이와 각막 테두리 기반 축약 측면 제한이며 면 접촉·공막 물성·적응형 절개를 완성한 것이 아닙니다. 거친 연결 절단은 상당한 절단 소실 면적을 만들 수 있습니다. 수정체는 111개 연결 입자, 유체는 단일 구획 모델입니다. IOL은 점 기반 감쇠 탄성 복원, 진입부는 절개 경로와 탄성 간극 모델입니다. 핵·피질의 입자 정체성과 잔여 질량을 구분하고, 캐뉼라의 실제 유입량이 가까운 피질-낭 부착을 해제하며 관류·흡인이 국소 피질 연결을 박리합니다. 이는 방사상 분류와 스프링에 기반한 근사이며, 연속체의 층간 유체 박리나 검증된 핵 회전 역학은 아직 없습니다. 화면과 공유하는 각막 돔·두께가 있는 홍채·후낭 곡면 및 실제 전낭 메시를 대상으로 이동 경로 전체의 팁 접촉을 검사합니다. 전낭이 막혀 있으면 수정체 조직에 대한 유화/흡인/수류 분리를 차단하고 전방 유체 흡인은 유지합니다. 활성 절개도는 전낭을 자를 수 있고, 각막 통과에는 실제 진입부 경로와 팁 반경을 수용하는 여유가 필요합니다. 연속체 각막/후낭 물성, 완전한 기구 축 접촉, 실제 안구 광학, 조직별 파괴 보정, 실제 기구 장비 라이브러리, 햅틱과 양손 하드웨어는 구현 범위 밖입니다. 기구 팁의 접촉은 구형 근사이며 도구의 축·날·턱 전체를 해결하지 않습니다. 각막/후낭의 국소 노출이 한계를 넘으면 주변 삼각형을 세분화해 실제 국소 결손을 만듭니다. 손상 후 충돌·표시·복기는 변경된 메시를 사용합니다. 두께가 있는 각막의 겉면 손상과 전층 통로를 구분하며, 외부 표면 샘플에서 안팎 경계를 모두 통과하는 경로가 검출된 부분만 각막 누출 면적으로 근사합니다. 표면 샘플은 512개로 제한되며 한도 도달 시 추가 분할이 제한됩니다. 후낭은 단일 막 결손 면적이 후방 유출에 연결됩니다. 후방 유출은 모델 밖 저장소로 향하는 단방향 경계이며 유리체·낙하 핵·IOL 지지 상실은 아직 구현되지 않았습니다. 노출 한계와 유출 계수는 검증되지 않은 공학적 상대값입니다.

실사 수술 영상과 동일한 외형이나 임상 정확도를 달성했다고 주장하지 않습니다. 완성형 임상 훈련기로 발전시키려면 전문의 평가, 조직/장비 데이터 보정, 정량 검증과 별도 자산 제작이 필요합니다. 본 배포는 전체 경로가 실행되는 전문 시뮬레이션 게임의 첫 통합 버전입니다.
