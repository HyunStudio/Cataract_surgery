## 3. 이번 검수에서 고친 결함

1. **3D 절개부 누출 케이스 완주 불가** (치명)
   - 증상: CLOSE 단계에서 봉합 부위의 작업 깊이(+0.04)가 IOL 깊이(−0.17)와 다르다. 그런데 도구 깊이가 단계가 바뀔 때만 맞춰져서, 클릭이 모두 `DEPTH`로 거부됐다.
   - 수정: 목표 깊이가 바뀌면(다른 부위의 합병증 처치) 도구도 그 깊이에서 시작한다.
   - 회귀 테스트: 모든 합병증을 3D에서 부위 클릭 한 번으로 처치할 수 있는지 확인한다.
2. **2D 프레임 저하** (11–27 fps)
   - 원인: 매 프레임 다음을 반복했다.
     - 라벨 약 45개를 다시 렌더링
     - 같은 크기로 smoothscale
     - 드레이프를 다시 그림
     - 파형 함수 계산
   - 수정:
     - 라벨 렌더링 결과를 캐시하는 `FontSet`
     - 줄바꿈 결과 캐시
     - 드레이프를 한 번만 그려 둠
     - 창과 캔버스 크기가 같으면 크기 조정 생략
     - 파형은 미리 계산한 표에서 보간(오차 0.0004)
   - 결과: 프레임 그리기 32ms → 약 12ms.
3. **3D 프레임 저하** (33–36 fps)
   - 원인:
     - HUD가 한글 라벨 약 38개를 매 프레임 렌더링(개당 0.7ms)
     - 단계가 바뀔 때마다 자동 저장을 동기식으로 기록(디스크 지연이 최대 0.3초)
   - 수정: HUD 텍스트·맞춤·줄바꿈 캐시, 자동 저장 백그라운드 기록(`BackgroundAutosave`).
     - 게임 상태는 메인 스레드에서 확보한다.
     - 최신 요청 하나만 기록한다.
     - 종료할 때 기록이 끝날 때까지 기다린다.
4. **개발용 문구 노출**
   - 3D 상단의 "INTERACTIVE 3D PROTOTYPE", 영어 경고문, FPS, "Mesh gap" 진단값이 늘 보였다.
   - 수정: 상단은 제목과 선택한 언어의 교육용 고지만 보여 준다. FPS와 진단값은 F3에서만 보인다. 하단의 중복 고지도 없앴다.
