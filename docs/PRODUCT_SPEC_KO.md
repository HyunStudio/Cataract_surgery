# 제품·게임 기획서 v1.1 — 백내장 수술 시뮬레이터

작성: 2026-10-12 | 상태: 설계 승인 전 초안 | 그래픽 목표: 2.5D → 선택적 실시간 3D

## 목표 및 범위
수술을 처음부터 끝까지 플레이하는 **교육·연구용 게임**. 핵심은 (1) 정교한 미세조작의 시각화, (2) 수술 단계와 조직 상태의 연속성, (3) 가상의 환자 반응·합병증 인지, (4) 재현 가능한 수행 데이터이다. 실제 의료행위에 활용하지 않는다.

**플랫폼**: Windows, Python 3.12, Pygame 기반 앱/UI. 첫 목표 1920×1080, DPI scaling으로 4K 지원. 마우스·키보드 입력; 향후 펜/컨트롤러 검토. 한국어/영어 UI 분리.

## 플레이 루프
Case selection → pre-op review → anesthesia/prep → entry → capsular task → lens removal → cortex cleanup → IOL insertion → close/verify → recovery/result. 각 단계는 '브리핑 → 조작 → 상태 평가 → 통과/재시도/중단' 구조이며 단순 클릭으로 자동 승리할 수 없다.

### Stage 1: 수술 전 확인
환자 ID/수술 부위 확인(가상), 백내장 유형·동공 크기·가상 안구 움직임·계획 IOL 표시. 평가: 확인 누락 여부와 단계 이해도. 실제 환자 데이터 금지.

### Stage 2: 마취 및 수술 준비
대표적인 국소/점안마취 기반 환경을 게임적으로 추상화; 마취 확인 카드, 환자 협조도, 불안/움직임, 소독·드레이핑 시각화. 약물명/용량/시술 해부학적 지침 입력 기능 없음. 이상 징후면 마취팀 평가 요청·수술 일시정지.

### Stage 3: 현미경 및 진입
현미경 초점·확대·조명 조절, 수술용 도구 선택, 눈 표면 접근. 도구와 구조물의 2.5D 깊이 충돌 판정. 절개 세부 술기 대신 진입 정확도·안정성·경계 이탈을 추상화.

### Stage 4: 전낭원형절개 미니게임
연속 폐곡선 경로의 안정성/매끈함/정확도 평가; 전낭 모델이 게임 내에서 변형. 난이도 상승 시 시야 감소 또는 안구 움직임. 실제 수술 가이드가 아닌 정규화된 가상 좌표 사용.

### Stage 5: 혼탁 수정체 제거
Phaco 장면: 혼탁 핵의 재질 시각화, 가상 파편 분해·흡인, 기구 근접과 조직 충돌 영향. 실제 초음파 설정, 에너지 수치, 흡인 압력/유량의 임상 제어값 사용 금지. 상태 변수: opacity, fragments, capsule_integrity, visibility, stress.

### Stage 6: 잔여 피질 정리
수정체낭 내 잔여물 시각화와 제거 진행률, 정상 조직 경계 보호, 잔여물 및 과도 조작 경고.

### Stage 7: 인공수정체 삽입
접힌 IOL의 가상 이동·펼침·중심 정렬. 접힘/복원 애니메이션과 전후 비교. 평가: 정렬 정도, 불필요한 접촉, 안정성. 수술 방법 지시 대신 게임 공간의 대상 영역만 표현.

### Stage 8: 마무리
잔여 가상 물질과 절개부 상태 확인, 전방 안정성, 누출 위험 이벤트, 인계 체크리스트. 환자/안구 상태가 불안정하면 종료 불가; 안전한 중단도 별도 엔딩.

### Stage 9: 회복과 결과
완수/안전 중단/합병증 관리/중대한 실패 4종 엔딩. 단계별 기록과 재플레이 히트맵, 점수, 오류 타임라인 표시.

## 마취과 영역 — 축소하지만 진짜 게임 상태와 연동
표시: ECG/HR, 비침습 혈압, SpO2, 환자 협조도(불안), 움직임 위험, 마취팀 알림. '모니터에 무작위 숫자 표시' 금지: 환자 모델의 상태와 모니터가 일치해야 한다. **교육용 합성 신호**만 사용하며 일반적인 백내장 수술의 국소마취 맥락을 반영한다. 저산소·불안·급격한 움직임 발생 시 사운드/화면 경보 → 손 동작 중단 → 마취과 평가 요청 → 복귀 또는 중단을 선택한다. 실제 임상 임계값을 처치 지침처럼 사용하지 않는다.

## 합병증·예외 분기
| 이벤트 | 원인(게임 내부) | 시각 피드백 | 기대 플레이 |
|---|---|---|---|
| 환자 움직임 | 협조도 하락/이벤트 | 현미경 영상 흔들림 | 멈추고 확인 |
| 동공 축소 | 시나리오 상태 | 작업 범위 축소 | 조작 위험 재평가 |
| 각막 혼탁 | 상태 악화 | 시야 블러·산란 | 시야 재평가 |
| 전낭 이상 | 경로 오류 | 낭 경계 왜곡 | 추가 위험 인지 |
| 후낭 파열 | 충돌 누적/시나리오 | 경고 및 구조 변형 | 작업 중단·에스컬레이션 |
| 유리체 이벤트 | 고위험 분기 | 영역 변화 | 에스컬레이션/안전 종료 |
| IOL 편위 | 정렬 오류 | 편심·기울기 | 위치 확인 |
| 누출 위험 | 마무리 검사 불충분 | 안정성 지표 저하 | 종료 보류 |
| 바이탈 경보 | 환자 가상 상태 | 모니터 강조 | 마취과 호출 |

**고위험 시나리오는 실제 치료법을 절차적으로 제공하지 않는다.**

## 점수와 패배 조건
기본 제안: 단계 완수 20 / 조직 보호 25 / IOL 위치 20 / 합병증 인지·대응 20 / 환자 안전 15점. 가중치는 **게임 내 가설**이며 교육적/임상적 타당성이 검증되지 않았다. 큰 위험을 무시하고 끝내면 실패. 적절한 시점의 중단은 긍정 평가 가능. 모든 평가 근거는 결과 화면에 설명.

## 난이도 및 접근성
튜토리얼/표준/고난도; 고대비, UI 배율, 키보드 조작 지원, 색각 접근성, 비점멸 알림, 흔들림 감소 옵션. 접근성 모드는 위험 이벤트를 숨기지 않고 정보 표시 형태만 바꾼다.

## 비기능 요구
고정 timestep과 렌더 FPS 분리; deterministic RNG seed; 세션 로그; 자동 저장/복구 지점; 렌더러 교체 가능 인터페이스; 장시간 플레이 메모리 누수 감시; 테스트 장면 60fps 목표(성능 목표일 뿐 현재 달성 주장 아님).

## 완료 정의
한 시나리오를 최초 진입부터 엔딩까지 무중단 플레이, GUI/단면도/모니터 상태 일치, 손상 이벤트와 안전 중단 검증, 합성 로그 재생성 가능, 최소 smoke test와 장면 전환 테스트 통과.
