# 수술 시뮬레이터로의 범위 정정 — 2026-10-26

사용자 요구: 게임이 아니라 실제 수술 현상을 계산하는 시뮬레이터. 입력은 우선 마우스·키보드. 기존 Godot 게임의 완료 보고는 이 요구의 완료를 의미하지 않는다.

## 설계 원칙

- Godot는 표시와 입력을 담당한다. 독립된 수치 모델이 기구와 조직의 상호작용을 계산한다.
- 목표 원 따라가기, 일정 시간 누르기, 미리 정한 영역 삭제, 점수로 수술 성공 판정은 새로운 핵심에서 제외한다.
- 현미경 시야에서 진입점을 지나는 기구 축, 각도, 삽입 깊이와 팁을 표시한다. 양손 기구를 선택 전환하고, 마우스 버튼은 집게/작동, Space는 가상 풋페달 역할을 한다. 실제 촉감은 제공하지 않는다.
- 전낭은 삼각형 막과 인장 제약으로, 집게는 실제 접점 고정과 이동으로, 파열은 국소 변형률에 따른 연결 해제로 계산한다. 표시용 원형 진행률이 파열을 결정하지 않는다.
- 수정체는 유한한 연결 입자 모델로, 기구 접촉·기계적 분절·흡인에 반응한다. 흡인은 가까운 자유 파편의 이동과 팁 유입으로 계산한다.
- 전방은 우선 단일 구획의 체적 보존과 유입/유출·압력 관계를 계산한다. 이는 CFD가 아니며 실제 안압/장비 설정으로 해석하지 않는다.
- 시뮬레이션 계수는 비보정 연구값으로 표시한다. 조직 물성과 기구 치수를 실측/문헌에 맞춰 보정하기 전에는 임상적 정확성을 주장하지 않는다.

## 구현과 검증 계획

1. 기구 운동학: 진입점에서 축까지 거리, 삽입 한계, 두 기구 위치 보존, 비정상 입력 거부를 테스트한다.
2. 전낭 모델: 무부하 안정성, 접촉 변형, 집게 견인, 과도 인장 파열, 시간 간격에 대한 안정성, 유한한 좌표/에너지 검사를 테스트한다.
3. 수정체/유체 모델: 국소 접촉과 분절, 질량 보존, 자유 파편의 흡인, 유입/유출 체적 변화를 테스트한다.
4. 별도 simulator 장면에 모델 상태를 실제 메시로 표시하고 접촉·변형·파열·파편 이동 전후를 GPU 캡처한다. 기존 게임은 비교용으로 보존한다.
5. 수치 검증과 현실 타당성 검증을 구분한 보고서를 남긴다. IOL 재료역학, 정밀 각막 광학, 복잡한 후낭/소대 역학, 실제 조직 데이터 보정은 미구현 항목으로 명시한다.
