# 물리 기반 수술 시뮬레이터 연구 모드

2026-10-26. 사용자의 범위 정정에 따라 게임 진행률/점수와 분리한 수치 모델을 구현했다. **현재는 부분적인 비보정 연구 시뮬레이터이며, 실제 수술 재현을 완성했다고 볼 수 없다.**

## 실행과 조작

Windows 연구 빌드는 `godot/build/OphthoSim-Simulator.exe`와 같은 이름의 `.pck`를 함께 둔다. 소스는 `tools/run-godot.ps1`, 예전 게임은 같은 스크립트의 `-Game` 옵션으로 실행한다. Godot 기본 장면은 `simulator.tscn`이다.

- 마우스 이동: 선택 기구의 진입점 기준 축 방향.
- 휠: 축을 따라 삽입/인출. Q/E: 상하 각도. Shift+휠: 현미경 확대.
- Tab: 두 기구 중 조작할 기구 전환. 다른 기구의 위치와 수동 접촉은 유지한다.
- 1–7 또는 왼쪽 버튼: 집게, 절개도, 유화 프로브, 관류/흡인, 캐뉼라, 인젝터, 조작 기구.
- 왼쪽 누름: 집게로 가까운 전낭 정점 파지/견인 또는 절개도로 가까운 연결 절단.
- Space: 가상 유화/흡인 페달. 실제 장비 설정이나 실제 풋페달 힘을 재현하지 않는다.
- F2: 계산 메시 격자 확인. Esc: 정지/재개. R: 조직 초기화. S: 수치 관측 기록 저장.

기구는 진입점 밖에서 시작한다. 삽입과 각도를 조절해 팁이 실제 모델 표면에 닿아야 한다. 선택 전환·포커스 이탈 시 집게와 페달을 해제하며, 페달은 놓은 뒤 새로 눌러야 재작동한다. 조작은 연구 모델 사용법이며 실제 환자 수술 지침이 아니다.

## 실제 계산되는 것

### 전낭

217개 정점, 396개 초기 삼각형, 가장자리 고정 막. XPBD 인장 제약, 감쇠, 국소 구형 팁 접촉, 가까운 정점 파지와 견인, 변형률 기준 연결 파열을 계산한다. 파열된 연결에 속한 면을 실제 렌더 토폴로지에서 제거한다. 미리 지정한 원을 따라 면을 없애는 방식이 아니다.

현재 삼각형 면적·법선으로 압력 하중을 분배하고, 원래 면적과 표면 밀도로 계산한 정점 질량을 통해 변위에 반영한다. 단일 구획의 합성 압력 변화가 `0.3*(pressure-1)` 하중으로 전달된다. 이 배율·밀도·강성·파열 기준은 인체 물성으로 보정되지 않았다. `max_strain`은 순간값이 아닌 관측된 최대 인장 변형률이고 `strain_energy`는 연구용 제약 에너지 대용값이며 Joule로 해석하지 않는다.

### 수정체와 유체

111개 질량 입자와 729개 초기 스프링 연결. 가까운 기구의 기계적 변형과 국소 유화 작용이 연결을 끊는다. 연결에서 풀린 입자는 흡인력으로 이동하고 팁 입구에 실제 도달했을 때만 제거 질량으로 옮긴다. 분절만으로 질량이 없어지지 않는다. 선택/비선택 기구의 비작동 팁도 접촉한다.

유입·유출에 따른 체적 보존, 조직에 의한 흡인 입구 차폐, 체적에 대한 합성 압력 관계를 단일 구획 모델로 계산한다. 압력·유량·질량은 정규화된 연구값이다. 실제 안압, 관류 높이, 진공압, 초음파 출력의 단위나 설정으로 바꾸지 않는다. CFD가 아니다.

## 검증한 것

- `test_capsule_solver`: 무부하 안정성, 고정 경계, 접촉과 견인 변형, 파열과 토폴로지 변화, 양/음 압력 하중, 비선택 팁 접촉, 잘못된 값 거부, 초기화.
- `test_lens_fluid_solver`: 무부하 평형, 국소 연결 파손, 분절 중 질량 보존, 입구까지의 파편 이동·흡인, 전체 질량 보존, 비작동/비선택 팁 접촉, 유입·유출 균형과 체적 변화, 차폐, 극단 입력 안정성.
- `test_instrument_rig`: 진입점·기구 축·삽입 길이 제약과 비정상 입력 거부.
- `test_simulator`: 두 기구 위치 보존, 포커스와 페달 잠금, 초기화, 모델 통합 유한성.
- `test_simulator_render`: 실제 기구 제약으로 전낭 접촉·견인·파열, 국소 유화/흡인과 GPU 표시. RTX 3070 Laptop GPU에서 0 failures. 고정 팁으로 3초 국소 작용했을 때 약 5.4% 질량만 흡인되어 전체 시야가 자동 제거되지 않는 것을 확인했다.
- 기존 Godot 5개 묶음도 통과했다. 기존 Python 회귀 검증은 별도로 유지한다.

기록은 `user://physics_observations.json`에 수치 관측을 저장한다. 완전한 입력/수치 상태 리플레이는 아직 제공하지 않는다. 기존 게임의 JSONL 재생과 혼동하지 않는다.

## 여전히 구현·검증이 필요한 것

- 인체 조직 데이터에 근거한 단위·물성·파열 에너지·기구 크기 보정과 민감도/수렴성 검증.
- 유한 두께·굽힘·찢김 전파, 후낭·소대·각막과 수정체의 양방향 접촉·유체 결합.
- 실제 기구 형상 전체의 충돌, 절개창 생성/변형과 진입 제약, 양손 파지의 지속 제어. 현재 접촉체는 팁 구형 근사다.
- IOL 재료역학과 삽입, 정확한 현미경/각막 광학. 인젝터는 현재 표시만 있고 재료 전달을 계산하지 않는다.
- 실제 기구 컨트롤러·풋페달·햅틱과 전문가 평가. 마우스는 손의 실제 운동·촉감을 재현하지 않는다.
- 전체 실시간 성능 보장. 느린 프레임에서 오래된 기계적 갱신을 여러 번 밀어 넣지 않고 한 번만 계산하므로 부하가 크면 시뮬레이션 시간이 현실보다 느리게 진행될 수 있다. 이전 게임의 59.97FPS 결과를 이 모드에 적용하지 않는다.

유한한 결과와 단위 테스트 통과는 수치 수렴성, 현실적 물성, 임상 교육 효과를 증명하지 않는다. “게임에서 물리 기반 연구 모델로 핵심 전환”한 현재 상태와 “실제 수술을 타당하게 재현하는 완성 시뮬레이터”라는 최종 목표를 구분한다.
