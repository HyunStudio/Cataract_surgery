# OphthoSim-AI 사용자 가이드 (한국어)

교육·연구용 **합성** 백내장 수술 시뮬레이터입니다. 화면의 모든 수치·파형·합병증·점수는 게임 내 가상 값이며, 실제 술기 지침·약물 용량·장비 설정을 제공하지 않습니다. 의료기기나 술기 자격 평가 도구가 아닙니다.

## 1. 설치와 실행 (Windows, Python 3.12 이상)

```powershell
git clone https://github.com/HyunStudio/Cataract_surgery.git
cd Cataract_surgery
python -m pip install -r requirements.txt
python main.py --lang ko                       # 2.5D 게임 (한국어 화면)
python main.py --case haze --difficulty hard --lang ko --seed 3
python main.py --resume                        # 자동 저장된 케이스 이어하기
```

3D 버전(실험적, OpenGL 3.3 필요):

```powershell
python -m pip install -r requirements-3d.txt
python -m ophthosim.gl_surgery --lang ko --case decenter
```

한국어 글꼴은 Windows 기본 **맑은 고딕**을 사용합니다. 게임 중 `L`로 한국어/영어를 바꿀 수 있습니다.

## 2. 진행 순서

| 단계 | 할 일 | 조작 |
|---|---|---|
| 수술 전 확인 | 케이스(1–9)·난이도(D)를 고른 뒤 환자 식별·수술 부위·IOL 계획 세 항목 확인 | Space를 누를 때마다 다음 항목 체크 → 마지막에 시작, 또는 항목 클릭 |
| 마취·준비 | 마취팀 준비 확인 (약물 조작 없음) | Space |
| 수술 진입 | 빛나는 세 목표 선택 | 클릭 |
| 전낭 과제 | 점선 원을 따라 그리기 | 누른 채 드래그 |
| 수정체 제거·피질 정리 | 작업 범위 안에서 혼탁 제거 | 누르고 있기 |
| IOL 삽입 | 광학 중심 근처 클릭 | 새로 클릭 (누른 채 넘어가지 않음) |
| 최종 확인 | 정렬·절개부·인계 확인 | 왼쪽 패널 클릭 또는 1–3 |
| 결과 | 점수 근거·타임라인 확인 | E 저장, R 다시 하기 |

단계마다 맞는 **기구**가 필요합니다: 진입 칼 → 전낭 겸자 → 초음파 핸드피스 → 관류·흡인기 → IOL 주입기. 튜토리얼·표준은 자동 선택되고, **고난도는 직접 고릅니다**(`T` 또는 화면 아래 기구 트레이 클릭). 잘못된 기구로 조작하면 거부되고 기록됩니다.

## 3. 시나리오 (수술 전 화면에서 숫자 키 1–9, 0)

| 키 | 케이스 | 발생 사건 (가상) | 바람직한 대응 |
|---|---|---|---|
| 1 | 정상 | 없음 | 안전하게 완료 |
| 2 | 환자 움직임 | 전낭 단계 진입 시 움직임 | 멈추고 A로 평가 |
| 3 | 바이탈 경보 | 수정체 제거 중 모니터 경보 | 보류 후 평가 |
| 4 | 수정체낭 이벤트 | 낭 손상 경보 | 평가하면 **안전 중단**으로 종료 |
| 5 | 작은 동공 | 동공 축소 | 평가 후 좁아진 작업 범위에서 계속 |
| 6 | 각막 혼탁 | 시야 흐림 | 평가 후 일부만 맑아짐 |
| 7 | IOL 편위 | 최종 확인 단계에서 IOL이 치우침 | 평가 → 중심을 다시 클릭 → 정렬 확인 |
| 8 | 절개부 누출 | 최종 확인 후 종료 보류 | 평가 → 절개부 안정성 재확인 |
| 9 | 유리체 이벤트 | 피질 정리 중 고위험 분기 | 평가하면 **안전 중단**으로 에스컬레이션 |
| 0 | 무작위 | 시드로 위 사건 중 하나 선택(확률·출처 로그 기록) | — |

어떤 케이스든 전낭 가이드를 여러 번 벗어나 그리면 **전낭 경계 불규칙** 경보가 한 번 발생합니다. 그 뒤 단계에서는 수정체낭 스트레스가 1.5배 빨리 쌓입니다. 수술 전 화면에는 가상 환자 카드가 표시됩니다(ID, 수술 눈 OD/OS, 혼탁 등급, 동공, IOL 계획).

## 4. 난이도

| | 튜토리얼 | 표준 | 고난도 |
|---|---|---|---|
| 목표 허용 범위 | 넓음 | 기준 | 좁음 |
| 가이드 원·IOL 십자선 | 표시 | 없음 | 없음 |
| 기구 선택 | 자동 | 자동 | 직접 |
| IOL 통과 기준 | 55% | 65% | 75% |
| 경보 방치 제한 | 없음 | 30초 | 15초 |
| 현미경 초점 | 자동 | 수동 | 수동 |

## 5. 경보와 결말

경보가 뜨면 수술 조작이 잠기고 **안전 보류** 패널에 원인, 권장 행동, 방치 시간이 표시됩니다. `A`(평가) 또는 `X`(안전 중단)로 대응하세요. 일시정지(Esc)로는 방치 타이머를 멈출 수 없습니다.

결말은 네 가지입니다.

- **시뮬레이션 완료**: 합병증 없이 끝까지 진행했습니다.
- **합병증 인지 및 관리 완료**: 경보를 인지하고 대응한 뒤 완료했습니다.
- **안전 중단**: 위험을 인지하고 멈췄습니다. 실패가 아닌 별도의 긍정적 결과입니다.
- **중대한 실패 (안전 거부권)**: 경보를 제한 시간 넘게 방치했습니다. 점수와 관계없이 실패로 표시됩니다.

## 6. 점수 (100점, 게임 내 가설 가중치)

| 항목 | 만점 | 근거 |
|---|---|---|
| 단계 완수 | 20 | 수술 단계 7개 중 완료 수 |
| 조직 보호 | 25 | 수정체낭 보존율 − 근접 실수 감점 |
| IOL 위치 | 20 | 최종 정렬 |
| 합병증 대응 | 20 | 경보 인지까지 걸린 시간 (3초 이내 만점) |
| 환자 안전 | 15 | 안전 거부권 없음 |

각 항목은 해당 단계가 실제로 평가된 뒤에만 점수가 들어갑니다. 결과 화면에 항목별 근거 문장과 사건 타임라인이 표시됩니다. 이 점수는 검증된 술기 척도가 아닙니다.

## 7. 화면 옵션 (2.5D)

| 키 | 기능 |
|---|---|
| 화살표 + Enter | 키보드만으로 모든 과제 수행 (Shift+화살표는 미세 이동) |
| Q / E, Shift+휠 | 도구 깊이. 단면도의 목표 깊이 띠 안에 있어야 조작이 적용됨 |
| 가운데 버튼 드래그 | 확대 상태에서 현미경 시야 이동 |
| ? 또는 도움 요청 버튼 | 도움 요청 (기록되지만 감점 없음) |
| F2 | UI 배율 100/125/150/200% |
| V | 깊이 단면도 크게 보기 |
| K | 손떨림 보정(커서 부드럽게) |
| 마우스 휠 / + − | 현미경 확대 (드래그 중에는 잠김) |
| [ ] | 초점 (화면 위 "초점 OK/~" 표시, 조작 판정에는 영향 없음) |
| , . | 조명 밝기 |
| H | 고대비 |
| C | 색각 이상자용 색상 (Okabe-Ito) |
| M | 움직임 줄이기 (경보는 그대로 유지) |
| S | 경보음 켬/끔 (깜박임 없이 짧은 두 음) |
| L | 한국어/영어 |
| F1 | 도움말 |
| G | CPU 3D 메시 미리보기 (조작 불가 학습용 보기) |

왼쪽 아래 **깊이 단면도**는 같은 상태값으로 각막·홍채·수정체·IOL과 현재 과제 깊이, 가상 도구 끝을 옆에서 보여줍니다.

## 8. 3D 버전 추가 조작

화살표 회전, `+ −` 확대, `Q/E` 도구 깊이, `T` 기구, `M`/`H` 움직임 줄이기·고대비, `F3` 프레임 시간, `S` 저장. 1440p·4K 화면에서는 HUD가 정수 배율로 커집니다. 자세한 내용은 [3D 안내](INTERACTIVE_3D_USAGE_KO.md)를 참고하세요.

## 9. 저장·재생·연구 데이터

**재생 보기:** `python main.py --replay session_logs\파일.replay.jsonl`
- 검증된 기록을 한 단계씩 다시 봅니다.
- Space 재생/정지, → 한 단계, +/- 속도, End 끝으로, Esc 종료.
- 재생 중에는 어떤 명령도 새로 보내지 않습니다.

**실행 옵션:**
- `--confirm-abort`: X를 두 번 눌러야 안전 중단이 확정됩니다.
- `--condition low_visibility`: 시야 제한 연구 조건입니다. 접근성 옵션과 별개이며 내보낼 때 기록됩니다.


`E`(2.5D) 또는 `S`(3D)를 누르면 `session_logs/`에 다음 파일이 저장됩니다.

- 사건 기록 `*.jsonl`
- 검증 가능한 재생 기록 `*.replay.jsonl`
- 사건 CSV
- 지표 CSV
- 설명 보고서 `*.report.json` (선택한 언어로 작성)

```powershell
python -m ophthosim.verify_replay session_logs\case_normal_standard_seed_7.replay.jsonl
python -m ophthosim.experiments examples\experiment_demo.json --out build\experiments\demo
```

실험 실행기는 가상 에이전트(이상적·부주의·느림·무반응)로 케이스 × 난이도 × 시드 조합을 반복 실행합니다. 연습/평가 시드를 나누려면 `examples\experiment_split.json`처럼 `splits`를 쓰세요. 두 집합이 겹치면 누설로 보고 거부합니다. 예전 형식의 기록은 `python -m ophthosim.migrate 이전.jsonl 새.jsonl`로 v3로 변환합니다. 모든 필드 설명은 [데이터 사전](DATA_DICTIONARY.md)에 있습니다. 모든 재생 기록을 검증하고 지표 CSV와 요약을 만듭니다. 이 결과는 측정 도구가 안정적인지 확인하는 용도이며, 사람의 실력을 뜻하지 않습니다.

**자동 저장**: 단계가 바뀔 때와 창을 닫을 때 `session_logs/autosave.replay.jsonl`이 갱신됩니다. 다음 실행 때 `--resume`으로 정확히 같은 상태에서 이어갈 수 있습니다. 위변조된 파일은 거부되고, 끝난 케이스는 자동 저장 파일을 지웁니다.

## 10. 성능 측정 (본인 Windows PC에서 확인 필요)

```powershell
python -m ophthosim.gl_benchmark --seconds 60 --size 1920x1080 --out build\benchmark\gl08.json
python -m ophthosim.gl_benchmark --seconds 300 --size 1920x1080 --scene-switch-every 120 --out build\benchmark\gl07.json
```

결과 JSON, 모니터 주사율, 그래픽 드라이버 버전, 스크린샷을 함께 [GPU 검증 체크리스트](GPU_VALIDATION_CHECKLIST.md)에 기록해 주세요. 소프트웨어 렌더러로 측정한 값은 하드웨어 증거로 인정되지 않습니다.

## 11. 한계

- 조직 변형 물리, 실제 광학 굴절, 힘 피드백은 기획서의 명시적 비범위입니다.
- 3D 안구는 앞쪽이 열린 공막 절개(cutaway) 메시를 사용합니다.
- 해부학 형상은 교육용 단순화이며 의학적으로 검증되지 않았습니다.
- Windows RTX 3070에서 GL01–GL10을 측정했습니다(1080p 평균 5.56ms). AMD Radeon 대상 측정, 배율 100%가 아닌 화면, 4K 가독성의 사람 확인, 전문가 내용 검토는 남아 있습니다.
