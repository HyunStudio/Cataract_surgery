# OphthoSim-AI 사용자 가이드 (한국어)

교육·연구용 **합성** 백내장 수술 시뮬레이터입니다. 화면의 모든 수치·파형·합병증·점수는 게임 내 가상 값이며, 실제 술기 지침·약물 용량·장비 설정을 제공하지 않습니다. 의료기기나 술기 자격 평가 도구가 아닙니다.

## 1. 설치와 실행 (Windows, Python 3.12 이상)

```powershell
git clone https://github.com/HyunStudio/Cataract_surgery.git
cd Cataract_surgery
python -m pip install -r requirements.txt
python main.py --lang ko                       # 2.5D 게임 (한국어 화면)
python main.py --case haze --difficulty hard --lang ko --seed 3
python main.py --resume                        # 자동 저장된 케이스 이어하기
```

3D 버전(실험적, OpenGL 3.3 필요):

```powershell
python -m pip install -r requirements-3d.txt
python -m ophthosim.gl_surgery --lang ko --case decenter
```

한국어 글꼴은 Windows 기본 **맑은 고딕**을 사용합니다. 게임 중 `L`로 한국어/영어를 바꿀 수 있습니다.

## 2. 진행 순서

| 단계 | 할 일 | 조작 |
|---|---|---|
| 수술 전 확인 | 케이스(1–9, N)·난이도(D)를 고르고, **환자 차트**(나이·동반 질환·복용 약물 계열·기준 활력징후)를 읽은 뒤 환자 식별·수술 부위·IOL 계획 확인 | Space를 누를 때마다 다음 항목 체크 → 마지막에 시작, 또는 항목 클릭 |
| 마취·준비 | 마취팀 준비 확인 (약물 조작 없음) | Space |
| 절개 | 각막도로 주절개, 보조절개도로 보조절개 2곳, 이어서 점탄물질(V)로 전방 유지 | 클릭, V |
| 전낭원형절개 | 낭절개침·겸자로 점선 원을 따라 그리기 | 누른 채 드래그 |
| 수력분리 → 초음파 유화 | D로 수력분리 후 작업 범위 안에서 핵 제거 | D, 누르고 있기 |
| 피질 정리 | 관류흡인(I/A)으로 남은 피질 제거 | 누르고 있기 |
| IOL 삽입 | 낭 안에 점탄물질(V) → 주입기로 광학 중심 근처 클릭 | V, 새로 클릭 |
| 최종 확인 | 정렬·절개부·인계 확인 | 왼쪽 패널 클릭 또는 1–3 |
| 결과 | 점수 근거·타임라인 확인 | E 저장, R 다시 하기 |

**기구 15종**

- 단계 기구 9종: 각막도, 보조절개도, 점탄물질 주입관, 낭절개침, 낭원형절개 겸자, 수력분리 주입관, 초음파 유화 핸드피스, 관류흡인(I/A), IOL 주입기
- 상황 기구 6종: IOL 갈고리, 홍채 갈고리, 수정체낭 긴장링(CTR), 소작기, 전방 세척, 봉합사

튜토리얼·표준에서는 소독 간호사가 단계 기구를 건네주지만, **상황 기구는 항상 직접 고릅니다**(`T`/`Shift+T` 또는 화면 아래 두 줄 트레이). 고난도는 단계 기구도 직접 고릅니다. 상황에 맞지 않는 기구를 쓰면 거부되고 안전 점수가 깎입니다.

손에 든 기구는 커서 위치에 기구 모양으로 표시됩니다. 출혈(절개부 혈액, 전방 아래 혈액층), 적색반사 소실, 홍채 탈출, CTR, 홍채 갈고리, 봉합도 2D·3D 화면에 그려집니다.

## 3. 시나리오와 처치

합병증이 생기면 먼저 **안전 보류**가 뜹니다(`A` 평가 또는 `X` 안전 중단). 평가한 뒤에는 **처치 대기** 카드가 남고, 맞는 기구를 맞는 부위에 써야 해결됩니다. 어떤 기구인지는 튜토리얼에서만 알려 줍니다. **중대 합병증**이 처치되지 않은 채 하던 작업을 계속하면 실패입니다.

| 키 | 케이스 | 발생 사건 (가상) | 처치 |
|---|---|---|---|
| 1 | 정상 | 없음 | — |
| 2 | 환자 움직임 | 전낭원형절개 중 움직임 | 평가 (활력징후가 기준으로 돌아옴) |
| 3 | 바이탈 경보 | 초음파 유화 중 모니터 경보 | 평가 |
| 4 | 후낭 파열 (**중대**) | 후낭 손상 | `B` 선임의 호출(고랑 IOL로 계속) 또는 `X` |
| 5 | 작은 동공 (당뇨) | 동공 축소 | 동공 가장자리에 홍채 갈고리 |
| 6 | 각막 혼탁 (푹스 이상증) | 시야 흐림 | 평가 |
| 7 | IOL 편위 | 최종 확인 중 IOL이 치우침 | 중앙에서 IOL 갈고리 |
| 8 | 절개부 누출 | 최종 확인에서 누출 | 주절개에 봉합 |
| 9 | 홍채 탈출 (알파차단제) | 홍채가 절개부로 빠져나옴 | 홍채 갈고리 — 방치하면 홍채 손상 → 전방출혈 |
| N | 소대 약화 (낙설) | 수정체가 한쪽으로 기움 | 중앙에 CTR — 방치하면 소대 파열 → 후낭 파열 |
| N | 절개부 출혈 (항응고제) | 절개부에서 혈액이 각막 위로 번짐 | 절개부에 소작기 |
| N | 전방출혈 | 전방 아래에 혈액층, 방치하면 점점 차오름 | 전방 세척 |
| N | 맥락막상 출혈 (**중대**) | 적색반사 소실, 전방이 얕아짐, 혈압·맥박 상승 | 즉시 절개부 봉합 → 안전 중단 |
| N | 무작위 | 시드로 위 사건 중 하나 선택(로그에 기록) | — |

술기 때문에 생기는 합병증도 있습니다. 점탄물질 없이 낭을 절개하면 안전 범위가 좁아지고, 바깥쪽으로 당기면 **절개 파열**이 생깁니다(점탄물질로 처치). 방치하면 후낭 파열로 번집니다. 수력분리를 건너뛰거나 작업 범위 가장자리에서 조작하면 **조직 스트레스**가 쌓이고, 한계를 넘으면 후낭이 파열됩니다. 항응고제를 복용하는 환자는 출혈이 더 많습니다.

## 5. 경보와 결말

경보가 뜨면 수술 조작이 잠기고, 수술 부위 아래쪽 **안전 보류** 카드에 원인, 권장 행동, 방치 시간이 표시됩니다. 합병증 모습은 카드에 가리지 않고 계속 보입니다. 일시정지(Esc)로는 방치 타이머를 멈출 수 없습니다.

결말은 다섯 가지입니다.

- **시뮬레이션 완료**: 합병증 없이 끝까지 진행했습니다.
- **합병증 처치 완료**: 합병증을 인지하고 처치한 뒤 완료했습니다.
- **합병증 미해결**: 처치하지 않은 합병증을 남긴 채 끝났습니다.
- **안전 중단**: 위험을 인지하고 멈췄습니다. 실패가 아닌 별도의 긍정적 결과입니다.
- **중대한 실패**: 경보를 제한 시간 넘게 방치했거나, 중대 합병증을 처치하지 않고 작업을 계속했습니다.

## 6. 점수 (100점, 게임 내 가설 가중치)

| 항목 | 만점 | 근거 |
|---|---|---|
| 단계 완수 | 20 | 수술 단계 7개 중 완료 수 |
| 조직 보호 | 25 | 수정체낭 보존율 − 근접 실수 감점 |
| IOL 위치 | 20 | 최종 정렬 |
| 합병증 대응 | 20 | 경보 인지까지 걸린 시간 (3초 이내 만점), 미처치면 절반 |
| 환자 안전 | 15 | 실패·미해결이면 0. 술기 누락(점탄물질·수력분리), 잘못된 기구, 스트레스 경고마다 감점 |

각 항목은 해당 단계가 실제로 평가된 뒤에만 점수가 들어갑니다. 결과 화면에 항목별 근거 문장과 사건 타임라인이 표시됩니다. 이 점수는 검증된 술기 척도가 아닙니다.

## 7. 화면 옵션 (2.5D)

| 키 | 기능 |
|---|---|
| 마우스 휠 / + − | 현미경 확대 (드래그 중에는 잠김) |
| [ ] | 초점 (화면 위 "초점 OK/~" 표시, 조작 판정에는 영향 없음) |
| , . | 조명 밝기 |
| H | 고대비 |
| C | 색각 이상자용 색상 (Okabe-Ito) |

| S | 경보음 켬/끔 (깜박임 없이 짧은 두 음) |

| G | CPU 3D 메시 미리보기 (조작 불가 학습용 보기) |

왼쪽 아래 **깊이 단면도**는 같은 상태값으로 각막·홍채·수정체·IOL과 현재 과제 깊이, 가상 도구 끝을 옆에서 보여줍니다.

## 8. 3D 버전 추가 조작

화살표 회전, `+ −` 확대, `Q/E` 도구 깊이, `T`/`Shift+T` 기구(아래 기구 줄 클릭도 가능), `V` 점탄물질, `D` 수력분리, `B` 선임의 호출, `M`/`H` 움직임 줄이기·고대비, `F3` 프레임 시간, `S` 저장. 1440p·4K 화면에서는 HUD가 정수 배율로 커집니다. 자세한 내용은 [3D 안내](INTERACTIVE_3D_USAGE_KO.md)를 참고하세요.

## 9. 저장·재생·연구 데이터

`E`(2.5D) 또는 `S`(3D)를 누르면 `session_logs/`에 다음 파일이 저장됩니다.

- 사건 기록 `*.jsonl`
- 검증 가능한 재생 기록 `*.replay.jsonl`
- 사건 CSV
- 지표 CSV
- 설명 보고서 `*.report.json` (선택한 언어로 작성)

```powershell
python -m ophthosim.verify_replay session_logs\case_normal_standard_seed_7.replay.jsonl
python -m ophthosim.experiments examples\experiment_demo.json --out build\experiments\demo
```

실험 실행기는 가상 에이전트(이상적·부주의·느림·무반응)로 케이스 × 난이도 × 시드 조합을 반복 실행합니다. 모든 재생 기록을 검증하고 지표 CSV와 요약을 만듭니다. 이 결과는 측정 도구가 안정적인지 확인하는 용도이며, 사람의 실력을 뜻하지 않습니다.

**자동 저장**: 단계가 바뀔 때와 창을 닫을 때 `session_logs/autosave.replay.jsonl`이 갱신됩니다. 다음 실행 때 `--resume`으로 정확히 같은 상태에서 이어갈 수 있습니다. 위변조된 파일은 거부되고, 끝난 케이스는 자동 저장 파일을 지웁니다.

## 10. 성능 측정 (본인 Windows PC에서 확인 필요)

```powershell
python -m ophthosim.gl_benchmark --seconds 60 --size 1920x1080 --out build\benchmark\gl08.json
python -m ophthosim.gl_benchmark --seconds 300 --size 1920x1080 --scene-switch-every 120 --out build\benchmark\gl07.json
```

결과 JSON, 모니터 주사율, 그래픽 드라이버 버전, 스크린샷을 함께 [GPU 검증 체크리스트](GPU_VALIDATION_CHECKLIST.md)에 기록해 주세요. 소프트웨어 렌더러로 측정한 값은 하드웨어 증거로 인정되지 않습니다.

## 11. 한계

- 조직 변형 물리, 유리체 이벤트, 실제 광학 굴절, 힘 피드백은 구현 범위 밖입니다.
- 해부학 형상은 교육용 단순화이며 의학적으로 검증되지 않았습니다.
- 기구 사용은 실제 순서와 선택을 따르지만, 장비 설정값(에너지·흡인·유량)과 약물 용량은 다루지 않습니다.
- 실제 안구 모델은 `assets/models/`에 라이선스가 확인된 OBJ 파일을 넣을 때만 쓰입니다. 없으면 코드로 만든 절차적 안구가 쓰입니다.
- Windows RTX 3070에서는 자동 점검을 통과했습니다. AMD Radeon 대상 PC 점검, 사람의 최종 확인, 전문가 내용 검토는 아직 남아 있습니다.
