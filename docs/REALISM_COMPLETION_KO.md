# 실제 수술에 가까운 완성 목표

사용자 지시: 2026-10-27 실제 수술처럼 완성을 목표로 계속 진행. Codex 목표 상태는 active이며, 첫 통합판 전달을 전체 완성으로 취급하지 않습니다.

실제 환자·장비에 대한 임상적 정확도, 술기 자격 판정과 햅틱 검증은 별도 외부 검증 영역입니다. 게임의 외형/동작 완성이나 내부 테스트 통과를 임상 검증으로 표현하지 않습니다.

## 현재 모델의 근거와 공학적 선택

핵·피질·낭의 구분과 유입을 통한 분리라는 개념은 [AAO Cataract PPP](https://www.aao.org/Assets/a7c4e054-2b43-4ac9-869a-d858ed48bb21/638876828052630000/cataract-in-the-adult-eye-ppp-7-9-25)와 [Columbia University hydrodissection reference](https://www.vagelos.columbia.edu/departments-centers/ophthalmology/education/digital-reference-ophthalmology/lens-and-cataract/surgical-videos-and-others/hydrodissection)를 참고했습니다. 반지름에 따른 111개 입자 분류, 스프링 계수, 국소 작용 반경과 부착 감소율은 공학적 근사 선택이며, 이 자료에서 검증된 수치로 가져온 것이 아닙니다. 모델은 시술 교육 지침을 제공하지 않습니다.

## 다음 구현 순서

1. 입체 안구의 전체 증례/GPU/Windows 검증을 갱신. 낭편 반출·교체 기구의 인출/재진입·깊이 피드백을 확장.
2. 전낭과 도구의 연속 팁 접촉을 구현하고 실제 메시의 열린 부분을 사용함. 도구 축·날·턱의 접촉과 손상 반응을 확장.
3. 후낭·각막 국소 손상과 결손 기반 유출을 연결함. 유체 폐색 해제, 유리체·낙하 재료·IOL 지지 상실과 합병증 대응을 확장.
4. 안구·기구·수술실 외형과 깊이 피드백 개선, 실제 포인터 경로 전체 증례 검증.
5. 지속 GPU 부하·배포 검증 후 완료 기준 재검토.

## 2026-10-28 입체 형상 진행

기본 실행은 새 입체 안구이며 이전 고정 좌표 테스트는 명시적 legacy 표본으로 유지합니다. 새 기본 모드 자체의 전체 증례·손상·형상·각막 두께·mm 결과 표시를 별도로 검증합니다. 낭의 실제 삼각형 안에 수정체 입자가 들어가는지 검사하며, 중심 곡면식만 비교해 통과시키지 않습니다.

아직 수정체 입자 경계는 단순 외곽 제한이며 실제 낭의 모든 동적 접촉과 파열 후 낙하를 해결하지 않습니다. 현재 연속 절개는 연결을 끊지만 분리된 전낭편의 정상 반출 절차는 미완료입니다. 자동 통합 테스트 통과를 실제 마우스·키보드 전체 사용성이나 임상적 술기 재현의 완료로 간주하지 않습니다.
