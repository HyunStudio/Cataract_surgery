조직 손상은 실제 접촉 부위의 절개·에너지 속성을 사용합니다. 축·슬리브는 도구 전체의 초음파·절개 효과를 물려받지 않으며, 보수적 충돌 후보만으로 손상을 만들지 않습니다. 집게는 위치 이동 후 턱 상태를 검사하고 허용된 상태만 화면·전낭 몸통 형상·이력에 적용합니다. 벌리기가 막혀도 닫힌 집게를 이동할 수 있고, 사용자 입력을 놓으면 닫힌 형상만으로 자동 재파지하지 않습니다.
