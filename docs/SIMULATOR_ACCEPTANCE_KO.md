# 전문 3D 백내장 수술 시뮬레이터 완료 기준

2026-11-05 현재 소스와 실행 증거를 구분한 작업표다. 부분 수치 검사나 예전
교육 게임의 완주를 새 물리 경로의 전체 완성으로 취급하지 않는다. 완료율을
임의로 계산하지 않으며 아래 모든 항목의 실제 증거가 필요하다.

관찰 시간이 지났다는 이유로 재시작하지 않는다. 이 경로를 통과하더라도 위 표의
다른 수술 단계와 실제 입력·실시간·배포 항목은 별도로 검증해야 한다.
